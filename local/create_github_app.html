Create the audit GitHub App

Submits a manifest to GitHub with exactly three read-only permissions (Contents, Dependabot alerts, Metadata), no webhook, installable only on your account. GitHub shows you a confirmation page; click Create GitHub App there.

After you click Create on GitHub

  1. GitHub sends you to your homepage URL with ?code=... at the end of the address. Copy that code (it expires in 1 hour and works once).
  2. Exchange it for the App ID and private key. In AWS CloudShell (or any terminal with curl): 
    curl -s -X POST https://api.github.com/app-manifests/PASTE_CODE_HERE/conversions \
  -H "Accept: application/vnd.github+json" > app.json
jq -r .id app.json            # -> github_app_id
jq -r .pem app.json > app.pem # -> contents go into the GH_APP_PRIVATE_KEY secret
jq -r .html_url app.json      # the App's page
    On Windows PowerShell instead: 
    $r = Invoke-RestMethod -Method Post https://api.github.com/app-manifests/PASTE_CODE_HERE/conversions
$r.id
$r.pem | Out-File -Encoding ascii app.pem
  3. Paste the contents of app.pem into the GH_APP_PRIVATE_KEY repo secret, then delete app.pem and app.json.
  4. Open the App's page → Install App → your account → Only select repositories → the demo-* repos. The number at the end of the URL you land on is github_installation_id.
