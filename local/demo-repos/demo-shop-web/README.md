# demo-shop-web

Storefront API for the DevOps audit assistant demo (team: **web**). Dependencies are
intentionally outdated and the code is deliberately vulnerable. Nothing here is deployed.

- `src/server.js`: Express API (link previews, saved carts, marketing banners)
- `src/banner.js`: renders caller-supplied templates
- `scripts/build-dirs.js`: build-time helper (dev dependency only)
